# Rejected candidates

One line per rejected paper, with the reason. Written by `scout`.

- holidayflu (Ewing et al. 2016, bansallab/holidayflu, Python): rejected, README says one model output file needs about 2 GB; simulation scale unknown and likely large compute (scout, 2026-11-26).
- arXiv:0807.4260 (RBG08) Table 3 MCMC values (alpha, phi): rejected as a rerun target. The MCMC is 16 chains of 12,000 steps and each step is a cross-correlation over about 10,000 points; the paper's own Table 1 shows 5 to 369 s per single calculation on a 3 GHz processor, so the full chain is well over one CPU hour. Registered the cheap Table 1 counts claim instead.
- arXiv:0801.0006 (RBSG08, Roukema, Buliński, Szaniewska & Gaudin 2008, A&A 486, 55): rejected. The paper states a 12,000-step chain takes about 3 to 4 days per chain (Sect. 3, read from a model summary, not verbatim), so the MCMC is far beyond one CPU hour. Its claims also come from the same circles code, so it adds no new stack coverage.
- Stojic 2017 (ReScience-Archives/Stojic-2017, Hinton & Nowlan 1987 replication, R): rejected. Replication README says 'Simulations take some time - on a 16 core computer it takes about 8h.' Well over the one-hour CPU budget (scout, 2026-11-26).
- Petchey, Plebani & Pennekamp 2016 (ReScience-Archives repo, reproducing Benincà et al. 2008 Nature 451:822): rejected for now, claim not verifiable from here. The Nature paper is behind a login (idp.nature.com redirect, both article and PDF), so scout cannot locate a figure value; the repo README names no figure or value, and its code folder has no licence text filled in (scout, 2026-11-26). Re-open only with an accessible copy of the paper.
- Stachelek 2016 (ReScience-Archives/Stachelek-2016, R, Etherington 2012 replication): rejected. The replication article states no numeric value; its claims are qualitative (e.g. 'for only two source cells, the performance benefit ... was outweighed by a higher initialization cost'), so no pre-registrable number exists in the text (scout, 2026-11-26).
- Maggi 2020 (sabinomaggi/ten-years-challenge-pulsed-drive, Fortran, replicating Maggi 1996 J. Appl. Phys. 79:7860): rejected for now. Runtime is fine (about 5 and 7 minutes, verbatim), but the replication's text gives only run parameters, not a result value, and the 1996 original (doi 10.1063/1.362395) is not reachable from here, so no claim can be located (scout, 2026-11-26).
- rbg08-pds-table1-counts (Roukema, Buliński & Gaudin 2008, arXiv:0807.4260, Table 1 N_A 1317 / N_C 52): withdrawn by scout, 2026-11-26. The rerun mind blocked it twice (attempts 1 and 2) for a missing specification the paper does not give: no Table 1 invocation (circles has no alpha, r2 or N_p flags) and no seed value (footnote a says only 'the same initial seed'). The authors' reproduce_RBG08.sh builds the code and stops before any Table 1 run. Scout will not guess a seed or flags, so the claim cannot be pre-registered as written. Re-register only with an authors' invocation or a different, fully specified claim.
